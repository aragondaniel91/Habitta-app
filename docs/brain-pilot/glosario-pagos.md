# Glosario de estados de pago

- **Borrador (`draft`):** El pago fue creado pero aún puede editarse y no se ha enviado para revisión.

- **Enviado (`submitted`):** El pago fue remitido para revisión y espera que una persona autorizada lo valide.

- **En revisión (`under_review`):** Una persona revisora ha tomado el pago para comprobar su información, comprobante y aplicación.

- **Corrección solicitada (`correction_requested`):** El pago requiere que quien lo registró corrija información o el comprobante antes de volver a enviarlo.

- **Aprobado (`approved`):** El pago fue validado, aplicado y aprobado; su importe queda reconocido en el flujo financiero.

- **Rechazado (`rejected`):** El pago no superó la revisión y no se aprueba; el rechazo conserva un motivo.

- **Reversado (`reversed`):** Un pago previamente aprobado fue revertido con un motivo, deshaciendo su efecto en el registro financiero.
